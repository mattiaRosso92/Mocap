# Mocap
Private repository for developments on motion capture analysis (work in progress, will be transferred to the FREQ-NESS Toolbox)

The first developments are based on Bigand et al. (2024). 
The purpose is to release a toolbox for analyzing single participants and scale to dyads and larger groups within the same functions.

I will use this also as a backup of older versions, and as a way to avoiding multiple versions of the code.
